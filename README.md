# Enrique Moreno — Developer Portfolio

Portafolio web personal creado con HTML, CSS y JavaScript.

## Objetivo

Mostrar proyectos reales de desarrollo de software, especialmente aplicaciones en Python,
software para negocios y proyectos web.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Diseño responsive

## Proyectos mostrados

1. X by Ximena — Aplicación de escritorio
2. Portfolio Developer — Este sitio
3. Culpable POS — Próximo proyecto
4. X by Ximena Web — Próximo proyecto

## Ejecutar localmente

No requiere instalación.

1. Descarga la carpeta.
2. Abre `index.html` en tu navegador.

También puedes utilizar la extensión Live Server de Visual Studio Code.
